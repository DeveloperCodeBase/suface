# داشبورد مدیریت منابع آب استان سمنان

این پروژه یک دموی کاملاً فرانت‌اند با React + TypeScript + Vite است که برای «شبکه هوشمند ابتکار ویستا» طراحی شده و وضعیت سدهای استان سمنان و کشور را به صورت راست‌به‌چپ و فارسی نمایش می‌دهد.

## ویژگی‌ها
- ناوبری کامل شامل نوار بالا، منوی کناری و هفت نما (کلان، سد پایلوت، استان سمنان، ملی، هشدارها، داده‌ها، تنظیمات)
- داده‌های ساختگی با به‌روزرسانی زمان-واقعی شبیه‌سازی‌شده و نمودارهای Recharts
- طراحی واکنش‌گرا با Tailwind CSS، فونت «وزیرمتن» و پشتیبانی کامل از RTL
- جدول‌ها، فیلترها و امکاناتی نظیر خروجی CSV برای گزارش‌ها

## راه‌اندازی
```bash
npm install
npm run dev
```

در صورت نیاز می‌توانید از `npm run build` برای خروجی تولید و `npm run preview` برای مشاهده نسخه‌ی تولید استفاده کنید.
