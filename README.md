# داشبورد مدیریت منابع آب استان سمنان

این مخزن شامل یک دموی کاملاً فرانت‌اند برای «شبکه هوشمند ابتکار ویستا» است که جهت ارائه به «آب منطقه‌ای استان سمنان» طراحی شده است. کل سامانه به زبان فارسی، راست‌به‌چپ، واکنش‌گرا و بدون وابستگی به بک‌اند پیاده‌سازی شده و با استفاده از داده‌های ساختگی و به‌روزرسانی‌های شبه‌زنده وضعیت سدهای استان و کشور را نمایش می‌دهد.

## ارزش پیشنهادی و قابلیت‌ها
- **ناوبری یکپارچه** شامل نوار بالایی ثابت، منوی کناری قابل جمع‌شدن و هفت نمای مجزا: کلان، سد پایلوت، استان سمنان، ملی، هشدارها، داده‌ها و گزارش‌ها، تنظیمات.
- **نمایش شاخص‌ها و نمودارهای تحلیلی** با استفاده از Recharts (نمودار خطی، ناحیه‌ای، میله‌ای، ترکیبی) و کارت‌های KPI با آیکون و رنگ‌بندی متناسب.
- **داده‌های ساختگی قابل پیکربندی** برای سدها، استان‌ها، بارش، تبخیر، هشدارها و پیش‌بینی ۷ روزه؛ تمامی داده‌ها در فایل `src/data/mockData.ts` تعریف شده‌اند.
- **به‌روزرسانی شبه‌زنده**: یک `DataProvider` داخلی هر ۸ ثانیه با `setInterval` مقادیر تراز، دبی و هشدارها را اندکی تغییر می‌دهد تا حس زنده بودن ایجاد شود.
- **تجربه بصری مدرن** با Tailwind CSS، فونت «وزیرمتن»، کارت‌های گرد با سایه نرم، حالت روشن/تیره و رعایت کامل RTL.
- **امکانات تحلیلی و عملیاتی** مانند فیلتر و مرتب‌سازی جداول، انتخاب بازه زمانی، خروجی CSV، انتخاب ستون‌ها، نمایش نقشه‌های نمایشی برای استان و کشور و پنل هشدار با برچسب رنگی.

## معماری و ساختار پوشه‌ها
```
src/
  components/   اجزای قابل استفاده مجدد (نوار ناوبری، کارت KPI، جدول داده، نمودارها، لیست هشدار)
  context/      منبع داده سراسری به‌همراه منطق به‌روزرسانی شبه‌زنده
  data/         داده‌های ساختگی، سری زمانی و توابع کمکی محاسبه شاخص‌ها
  pages/        هفت نمای اصلی مطابق نیاز کارفرما
  main.tsx      نقطه ورود React + React Router + Context
```

## پیش‌نیازها
- Node.js نسخه 18 یا جدیدتر (پیشنهاد: LTS)
- npm نسخه 9 یا جدیدتر
- دسترسی به Git جهت کلون کردن پروژه از GitHub

## راه‌اندازی گام‌به‌گام از GitHub روی ویندوز
1. **نصب ابزارها**: از [nodejs.org](https://nodejs.org) نسخه LTS را دانلود و نصب کنید (npm به همراه Node نصب می‌شود). سپس Git را از [git-scm.com](https://git-scm.com) نصب نمایید.
2. **کلون کردن مخزن**:
   ```powershell
   git clone https://github.com/<your-org>/suface.git
   cd suface
   ```
3. **نصب وابستگی‌ها** (در PowerShell یا Terminal ویندوز):
   ```powershell
   npm install
   ```
4. **اجرای نسخه توسعه**:
   ```powershell
   npm run dev
   ```
   خروجی Vite شامل آدرس محلی (به‌صورت پیش‌فرض `http://localhost:5173`) است. مرورگر خود را باز کنید و از تجربه RTL فارسی استفاده کنید.
5. **ساخت نسخه تولیدی** (اختیاری):
   ```powershell
   npm run build
   npm run preview
   ```
   فرمان دوم نسخه ساخته‌شده را به صورت محلی سرو می‌کند تا قبل از استقرار بررسی شود.

## راه‌اندازی گام‌به‌گام از GitHub روی اوبونتو
1. **به‌روزرسانی پکیج‌ها و نصب ابزارها**:
   ```bash
   sudo apt update && sudo apt install -y curl git
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt install -y nodejs
   ```
2. **بررسی نسخه‌ها** (اختیاری اما توصیه‌شده):
   ```bash
   node -v
   npm -v
   ```
3. **کلون کردن مخزن**:
   ```bash
   git clone https://github.com/<your-org>/suface.git
   cd suface
   ```
4. **نصب وابستگی‌ها**:
   ```bash
   npm install
   ```
5. **اجرای سرور توسعه**:
   ```bash
   npm run dev -- --host
   ```
   سپس در مرورگر (روی همان ماشین یا شبکه محلی) به آدرس اعلام‌شده توسط Vite مراجعه کنید.
6. **ساخت و پیش‌نمایش نسخه تولید** (در صورت نیاز استقرار):
   ```bash
   npm run build
   npm run preview -- --host
   ```

## اسکریپت‌های npm
- `npm run dev`: اجرای Vite با HMR برای توسعه.
- `npm run build`: اجرای TypeScript compiler و ساخت باندل تولیدی Vite در پوشه `dist`.
- `npm run preview`: سرو نسخه تولیدی جهت تست نهایی.
- `npm run lint`: اجرای ESLint روی فایل‌های TypeScript/React و قوانین Tailwind.

## پیکربندی نقشه‌ها، سدها و هشدارهای سناریویی
- `src/config/maps.ts`: محدوده، مرکز و سطح بزرگ‌نمایی نماهای «ایران» و «استان سمنان» تعریف شده‌اند. با تغییر مختصات `center` یا بازه‌های `bounds` می‌توانید نقشه را روی استان یا حوضه دیگری متمرکز کنید.
- `src/config/dams.ts`: فهرست سدهای شاخص کشور (`NATIONAL_DAMS`) و سدهای استان سمنان (`SEMNAN_DAMS`) به‌همراه کاربری، ظرفیت و مختصات تقریبی درج شده است. هر رکورد دارای `status` (بهره‌برداری، در دست ساخت، مطالعاتی) و `purposes` است؛ برای تکمیل مختصات می‌توانید از سرویس‌های رسمی شرکت مدیریت منابع آب یا داده‌های GIS استفاده کنید. برای پوشش کامل ملی، پیشنهاد می‌شود دیتاست رسمی daminfo.wrm.ir یا نسخه آفلاین آن در Iran Open Data را به‌صورت برنامه‌نویسی‌شده وارد کنید.
- `src/config/alerts.ts`: ساختار `AlertConfig` توضیح، شدت، پیوند به سد/منطقه و فیلد `isRealData` را نگه می‌دارد. هشدارهایی که مستقیماً از گزارش‌های رسمی گرفته شده‌اند با برچسب «داده واقعی» نمایش داده می‌شوند و سناریوهای تمرینی با عنوان «سناریوی نمونه / داده فرضی» مشخص شده‌اند. برای افزودن هشدار جدید، شناسه یکتا (`id`) تعیین و در صورت امکان `damId` را با یکی از سدهای تعریف‌شده هماهنگ کنید تا روی نقشه هایلایت شود.

> نکته: مولفه `DamMap` به صورت پیکربندی‌پذیر از همین فایل‌ها تغذیه می‌شود؛ کافی است دام‌های جدید یا نماهای جدیدی اضافه کنید تا در صفحه ملی/استانی و پنل هشدارها نیز در دسترس باشند.

## نکات استقرار و رفع اشکال
- در محیط‌های بدون دسترسی مستقیم به `registry.npmjs.org` لازم است از کش داخلی یا تنظیمات proxy استفاده کنید؛ در غیر این صورت نصب وابستگی‌ها با خطای 403 مواجه می‌شود.
- برای میزبانی نسخه تولیدی کافی است محتوای `dist/` را بر روی هر وب‌سرور استاتیکی (مانند Nginx، GitHub Pages، Netlify) قرار دهید.
- در صورت نیاز به سفارشی‌سازی داده‌ها، فایل `src/data/mockData.ts` نقطه ورودی واحد برای تعریف سدها، سری زمانی، هشدارها و مقادیر پیش‌بینی است.
